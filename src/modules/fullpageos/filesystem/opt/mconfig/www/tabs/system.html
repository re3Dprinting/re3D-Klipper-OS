Run OS & Configurator update?

This will pull the latest Configurator UI, machine configs, Klipper, Moonraker, and Mainsail updates. The printer will reboot automatically when complete.

⚠ Klipper update detected
A Klipper firmware update is available. After this update completes and the system reboots, the Archimajor board must be re-flashed with the new firmware.

Reflash Archimajor board?

This will schedule a firmware flash on the next boot and immediately reboot the printer. The flash screen will appear — keep the USB cable connected throughout.

Restore from uploaded bundle?

Upload and restore print history? The current Moonraker database will be backed up, then overwritten, and Moonraker will restart.

Schedule customer open-box setup?

The next boot will show the unpacking guide and network choices instead of normal setup or printer control. This does not reboot now. The guide will keep appearing on boot until the customer finishes it.

The unpacking slides are placeholders until operations supplies the instructions and pictures.
