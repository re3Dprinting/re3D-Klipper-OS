Print History
Save/restore Moonraker’s print-history database.
• Save: copies ~/printer_data/database/moonraker-sql.db → /media/usb0/moonraker-sql.db.
• Restore: replaces the live DB with /media/usb0/moonraker-sql.db (current DB is auto-backed up).
Save history to USB
USB must be mounted at /media/usb0.
Restore history from USB
Backs up current DB as moonraker-sql.db.bak-YYYYmmdd-HHMMSS, then restarts Moonraker.
