Belt Tension Assistance
Compare StallGuard motor load before and after small belt adjustments. Lower readings generally indicate higher load, but friction, alignment, speed, motor temperature and current also affect the result. These are not tension units or a pass/fail test; Prusa's target numbers do not apply. Supports Cartesian printers with TMC5160 or TMC2130 drivers; the test temporarily uses spreadCycle.
Enter a whole number from -64 to 63, or leave blank to use the current driver setting. If 0 gives zero and 16 gives 1023, try 8. Failed tests suggest finer values using the signal bounds measured in this tab session. Higher SGT is less sensitive. This affects the measurement scale, not belt tension. The test enables StallGuard filtering and restores the original SGT and filter afterward. Use the same speed and SGT for before/after comparisons.
Test moves only the selected axis between 20% and 80% of its configured travel at the selected speed, then returns to the starting test point. It does not home or raise Z. Driver chopper mode and StallGuard measurement thresholds are restored after testing. All-zero readings are not usable belt-tension feedback. Compare references only at the same speed.
Home and clear the printer before testing. Never adjust belts while motors are moving. References are saved in this browser; compare only the same printer and motion settings.
