# re:3D Klipper OS Wiki

Practical guides for setting up your printer, getting repeatable results, and
finding help when something goes wrong.

> **Wiki starter:** These pages are drafts based on the repository, not
> hardware-validated operating procedures. Follow the operating and safety
> instructions supplied with your machine. Features and labels may vary by
> installed OS version.

## Machines shown in the Configurator

- Gigabot 4 and Gigabot 4 XLT
- Terabot 4
- GigabotX 2 and GigabotX XLT 2
- TerabotX 2

Appearing in the machine selector is not a guarantee that every accessory or
procedure applies. Check each guide's machine, board, and hardware requirements.

## Two interfaces, different jobs

**Printer Control (Mainsail)** is the main printing interface.
**Configurator** contains re:3D machine setup, network, tuning, and support tools.
Use the Configurator's **Printer Control** link to return to Mainsail.

## Documentation status

- **Draft:** needs technical or hardware review before publication as a procedure.
- **Verified:** a reviewer has recorded the tested OS revision and hardware.
- **Template:** a starting point for authors, not instructions for operators.
